# Prueba y configuración de playwright-cli
> Pre-requisitos: tener instalado [OpenCode](https://opencode.ai/) y Node.js 20 o superior (Recomendación: [instalar con nvm](https://github.com/nvm-sh/nvm)).

1. Instalar [playwright-cli](https://playwright.dev/docs/getting-started-cli)
2. Abrir OpenCode
3. Instruir al agente para que realice una lista de tareas en la 
web de prueba https://demo.playwright.dev/todomvc **mostrando el explorador**
    > Es posible que el agente no sea tan efectivo en el uso de la herramienta. 
        Para mejorar su desempeño tenemos que proveerle de la información de uso. Lo haremos a continuación
4. Instalando la [skill de playwright-cli](https://playwright.dev/docs/getting-started-cli#installing-skills) 
    (manual de uso para el agente)
5. Reiniciar OpenCode
6. Instruir al agente para volver a realizar la lista de tareas en la web de prueba
    > Con la skill instalade deberíamos obtener un uso mas efectivo de la herramienta (playwright-cli)
